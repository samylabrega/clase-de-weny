Física · Electrostática

Ley de Coulomb

Dos cargas se empujan o se jalan. Cuánto: F = k·|Q₁|·|Q₂| / d²

1El átomo

El núcleo tiene protones (+) y neutrones (0). Afuera giran los electrones (−). + y − se atraen: por eso el núcleo los sujeta.

  • Átomo neutro: nº protones = nº electrones.
  • Pierde e⁻ → ion +. Gana e⁻ → ion −.
  • Anillo de adentro, más cerca → atracción más fuerte.

2Iguales se repelen, opuestas se atraen

Mira las flechas: apuntan hacia afuera si se repelen y hacia la otra carga si se atraen.

++← →repelen
−−← →repelen
+−→ ←atraen

3La fórmula, desarmada

Cada color es una parte. Cambia una y mira qué le pasa a F.

×2 carga → F ×2
×2 las dos cargas → F ×4
×2 distancia → F ÷4
÷2 distancia → F ×4

Úsalos en todos los ejercicios. Cada hoja de abajo los sigue; con Paso a paso los ves uno por uno.

  1. 1
    Datos: a la izquierda, unidades convertidas (cm ÷ 100 = m; µ = 10⁻⁶). Debajo: HALLAR.
  2. 2
    Dibujo: cargas en línea con signo, distancias y flechas F₁₂ (de Q₂ sobre Q₁).
  3. 3
    Fórmula: escrita primero y despejada si hace falta.
  4. 4
    Sustitución: con unidades: N·m²/C², C, m².
  5. 5

  6. 6
    Resultado: en notación científica, con unidad.
  7. 7
    Eje x-y: flechas sobre el eje; FR suma si van al mismo lado, resta si van opuestas.
mili m = 10⁻³

5Ejemplo de la pizarra: tres cargas

Cada fuerza sobre Q₁ se calcula por separado; luego se juntan como flechas. Toca Q₃ para cambiar su signo y mira cómo gira F₁₃.

Pizarra

Tres cargas en línea: fuerza resultante sobre Q₁

Q₁ = 4 µC, Q₂ = 2 µC y Q₃ = 1 µC en línea, 2 m entre Q₁ y Q₂ y 2 m entre Q₂ y Q₃. Hallar la fuerza resultante sobre Q₁.

Datos

  • Q₁ = 4 µC = 4×10⁻⁶ C
  • Q₂ = 2 µC = 2×10⁻⁶ C
  • Q₃ = 1 µC = 1×10⁻⁶ C
  • d₁₂ = 2 m
  • d₁₃ = 2 m + 2 m = 4 m
  • k = 9×10⁹ N·m²/C²

HALLAR:

  • FR sobre Q₁
  1. 2Dibujo

    F₁₂ = fuerza de Q₂ sobre Q₁. Iguales se repelen (flecha se aleja), distintas se atraen (flecha va hacia la otra).

  2. 3Fórmula
    F = k·|Q₁|·|Q₂| / d²

    Una vez para F₁₂ y otra para F₁₃. Se usan los valores sin signo.

  3. 4Sustitución
    F₁₂ = (9×10⁹ N·m²/C²)(4×10⁻⁶ C)(2×10⁻⁶ C) / (2 m)²
    = 72×10⁹⁻⁶⁻⁶ N·m² / 4 m²
    F₁₃ = (9×10⁹ N·m²/C²)(4×10⁻⁶ C)(1×10⁻⁶ C) / (4 m)²
    = 36×10⁹⁻⁶⁻⁶ N·m² / 16 m²

    C·C se cancela con C² de k; m² arriba con m² abajo → queda N.

  4. 5Exponentes
    F₁₂ = 72×109−6−6 / 4 = 72×10⁻³ / 4
    F₁₃ = 36×109−6−6 / 16 = 36×10⁻³ / 16

    Multiplicar potencias → sumar exponentes: 9 + (−6) + (−6) = −3.

  5. 6Resultado
    F₁₂ = 18×10⁻³ N
    F₁₃ = 2.25×10⁻³ N
  6. 7Eje x-y y resultante

    Con Q₃ negativa, Q₃ atrae a Q₁: F₁₃ gira y apunta a la derecha. Gana la más grande (F₁₂), por eso FR sigue a la izquierda.

  7. ✓Revisión
    Signo
    F₁₂ a la izquierda (repulsión). F₁₃ a la izquierda si Q₃ +, a la derecha si Q₃ −. FR hacia la izquierda en los dos casos.
    Unidad
    N·m²/C² · C · C / m² = N ✓
    Orden
    10⁻³ N (milésimas de newton): normal para cargas de µC a metros. F₁₃ < F₁₂ porque Q₃ es menor y está al doble de distancia (÷4).

6Problema A · cargas iguales

Las dos cargas son la misma incógnita: la fórmula queda con Q².

Problema A

Dos cargas iguales: hallar Q

Dos cargas iguales separadas 300 cm se repelen con F = 4×10⁻³ N. Hallar el valor de cada carga.

Datos

  • F = 4×10⁻³ N
  • d = 300 cm = 3 m
  • Q₁ = Q₂ = Q
  • k = 9×10⁹ N·m²/C²

HALLAR:

  • Q
  1. 2Dibujo

    Se repelen → mismo signo. Flechas hacia afuera.

  2. 3Fórmula y despeje
    F = k·Q·Q / d² = k·Q² / d²
    F·d² = k·Q²
    Q² = F·d² / k
    Q = √(F·d² / k)
  3. 4Sustitución
    Q² = (4×10⁻³ N)(3 m)² / (9×10⁹ N·m²/C²)
    = (4×10⁻³ N)(9 m²) / (9×10⁹ N·m²/C²)
    = 36×10⁻³ / 9×10⁹ C²

    N·m² ÷ (N·m²/C²) = C².

  4. 5Exponentes
    Q² = (36/9)×10−3−9 = 4×10⁻¹² C²
    Q = √4 × √10⁻¹² = 2×10−12÷2 = 2×10⁻⁶ C

    Dividir potencias → restar exponentes. Raíz → exponente ÷2, por eso debe ser par. Si te sale impar (p. ej. 40×10⁻¹³), corre la coma: 4×10⁻¹² ✓.

  5. 6Resultado
    Q = 2×10⁻⁶ C = 2 µC

    Las dos valen 2 µC (las dos + o las dos −).

  6. ✓Revisión
    Signo
    Se repelen → mismo signo: ambas +2 µC o ambas −2 µC ✓
    Unidad
    √C² = C ✓
    Orden
    µC (10⁻⁶): típico. Prueba: 9×10⁹·(2×10⁻⁶)²/9 = 4×10⁻³ N ✓

7Problema B · una carga conocida

Se despeja la carga que falta. El signo sale de “atracción”.

Problema B

Conozco Q₁: hallar Q₂

La fuerza de atracción entre dos cargas es F = 3.6×10⁻² N y están separadas d = 600 cm. Si Q₁ = 4×10⁻⁶ C, hallar Q₂.

Datos

  • F = 3.6×10⁻² N (atracción)
  • d = 600 cm = 6 m
  • Q₁ = 4×10⁻⁶ C
  • k = 9×10⁹ N·m²/C²

HALLAR:

  • Q₂
  1. 2Dibujo

    Se atraen → signos distintos. Flechas una hacia la otra.

  2. 3Fórmula y despeje
    F = k·|Q₁|·|Q₂| / d²
    F·d² = k·|Q₁|·|Q₂|
    |Q₂| = F·d² / (k·|Q₁|)
  3. 4Sustitución
    |Q₂| = (3.6×10⁻² N)(6 m)² / [(9×10⁹ N·m²/C²)(4×10⁻⁶ C)]
    = (3.6×10⁻²)(36 m²) N / (36×10⁹⁻⁶ N·m²/C)

    N·m² ÷ (N·m²/C²·C) = C.

  4. 5Exponentes
    Abajo: 9×4 = 36 y 109−6 = 10³
    Arriba: 3.6×36 = 129.6 → 129.6×10⁻²
    |Q₂| = (129.6/36)×10−2−3 = 3.6×10⁻⁵ C

    Abajo se multiplica (sumar), luego se divide (restar): −2 − 3 = −5.

  5. 6Resultado
    Q₂ = −3.6×10⁻⁵ C
    = −36 µC (si Q₁ es +)
  6. ✓Revisión
    Signo
    Atracción → Q₂ de signo contrario a Q₁: negativa ✓
    Unidad
    C ✓
    Orden
    10⁻⁵ C = 36 µC. Prueba: 9×10⁹·4×10⁻⁶·3.6×10⁻⁵ / 36 = 3.6×10⁻² N ✓

8Problema C · densidad de carga

ρ = Q / V: carga por cada metro cúbico (C/m³). Tres letras, se despeja la que falta.

ρ = Q / V
Q = ρ · V
V = Q / ρ
Problema C

Densidad de carga: hallar el volumen

Hallar el volumen de una masa que contiene una carga Q = 6×10⁻¹⁵ C con densidad de carga ρ = 3×10⁻¹⁹ C/m³.

Datos

  • Q = 6×10⁻¹⁵ C
  • ρ = 3×10⁻¹⁹ C/m³

HALLAR:

  • V
  1. 2Dibujo

    ρ dice cuánta carga hay en cada m³ del cuerpo.

  2. 3Fórmula y despeje
    ρ = Q / V
    ρ·V = Q
    V = Q / ρ
  3. 4Sustitución
    V = 6×10⁻¹⁵ C / 3×10⁻¹⁹ C/m³

    C ÷ (C/m³) = C · m³/C = m³.

  4. 5Exponentes
    V = (6/3)×10−15−(−19) = 2×10−15+19 = 2×10⁴

    ¡Cuidado con el doble signo! Restar −19 es sumar 19.

  5. 6Resultado
    V = 2×10⁴ m³
    = 20 000 m³
  6. ✓Revisión
    Signo
    Volumen siempre positivo ✓ (Q y ρ tienen el mismo signo)
    Unidad
    m³ ✓
    Orden
    ρ es diminuta (10⁻¹⁹), así que hace falta mucho volumen para juntar Q: 10⁴ m³ tiene sentido. Prueba: 3×10⁻¹⁹ · 2×10⁴ = 6×10⁻¹⁵ C ✓
